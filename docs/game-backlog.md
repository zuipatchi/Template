# ゲームバックログ（作りたいもの）

作りたいゲームの仕様・アイデアを箇条書きで溜めておく場所。**ユーザーが自由に書く**。書き方が粗くても、`/feature` のヒアリングで仕様を詰めるのでかまわない。

- 実装が終わった項目はここから消し、[product.md](product.md)「ゲーム固有機能」に移す（Claude が `/feature` の最後に行う）
- `/feature` を実行すると、いちばん上の項目を拾ってヒアリングを始める（`/feature G-03` なら指定の項目）。作りたいものはプロンプトではなくここに書く
- 技術的な判断待ち・確認待ちは [tech-backlog.md](tech-backlog.md)（Claude 用）に書く

## 書き方

```markdown
### G-01 項目名
- 優先度: 高 / 中 / 低
- 状態: アイデア / 実装中
- やりたいこと（箇条書きで自由に）
- 決まっていること・決まっていないこと（あれば）
```

- ID は連番で振り、再利用しない
- 上から優先度の高い順に並べる（`/feature` はいちばん上の項目から作るので、行を入れ替えるだけで次に作るものを変えられる）
- 「状態」は、ヒアリングで仕様が固まると Claude が合意した仕様・完了条件を書き込み「実装中」に更新する（途中で止まっても次の `/feature` で再開できる）
